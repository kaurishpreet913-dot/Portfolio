# Personal Portfolio Website

## Overview

A responsive personal portfolio website designed to showcase technical projects, skills, and development work.

The portfolio provides a simple and organized interface for presenting projects and technical experience.

## Features

* Responsive web design
* Project showcase
* Technical skills section
* Clean and organized user interface
* Navigation between portfolio sections
* Contact section
* Mobile-friendly layout

## Projects

The portfolio showcases projects across different areas of software development and Artificial Intelligence, including:

### Traffic Sign Recognition System

A computer vision project using **ResNet50 transfer learning** and the **GTSRB dataset** to classify 43 traffic sign categories.

### NutriGuide

An AI-powered nutrition chatbot using the **Google Gemini API** to provide responses to nutrition and dietary queries.

### Spam Detection System

An NLP-based machine learning project using **text preprocessing, TF-IDF vectorization, and classification techniques** for spam detection.

### KiddoLock

An Android parental-control application focused on screen-time management and access restrictions.
